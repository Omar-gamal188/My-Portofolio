02.1 — Flagship · deep dive

AttackWeb: I built it,
broke it, then caught myself

A full offensive-and-defensive exercise on a deliberately vulnerable web app. The point wasn't just to find bugs — it was to prove I can sit on both sides: write the code, exploit it like an attacker, and detect the exploit like an analyst.

11,402Log entries analysed

01 Build

A Node.js + Express + MongoDB app with JWT auth, seeded with real vulnerabilities: unsanitised $regex search, an injectable login query, and no rate limiting on the login route.

02 Attack

From Kali: Nikto recon (8,101 requests in 23s), NoSQL injection, a regex data dump that exposed the whole user table with the payload .*, a brute-force run, and two privilege-escalation attempts.

03 Detect

A Python watcher tails the JSON access log, classifies each request through detection rules with a confidence score, and streams verdicts to a live browser dashboard over Socket.IO. Backed by 12 Splunk queries for analysis at scale.

Takeaway I keep coming back to: bcrypt stopped the login injection from fully succeeding even though the query itself was injectable — defence in depth is real.
